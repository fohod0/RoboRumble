🤖 Robo Rumble — Bluetooth WASD

How to connect

  1. Make sure Bluetooth is turned on on this laptop.
  2. Click Connect via Bluetooth below.
  3. In the popup, select your robot (e.g. RoboRumble-ESP1) and click Pair/Connect.
  4. Once it says Connected to…, hold your drive keys (default WASD) to drive — combine two for a turning drive, e.g. Forward+Right.

Drive equations

V = forward key (+1) / backward key (−1)  ·  H = right key (+1) / left key (−1)
Allowed: numbers, V, H, + − × ÷, parentheses. e.g. V + H, V - 0.5*H

Click a key above to rebind it — press any key to set it (swaps automatically if that key is already used elsewhere). Edit the drive equations above to change how V/H combine into wheel speed — invalid formulas are rejected and never reach the motors. Both are saved on this computer. Works in Chrome or Edge on desktop only — Web Bluetooth isn't supported in Safari or on iOS. Releasing all keys, clicking STOP, closing this tab, or losing the Bluetooth link all stop the motors immediately.
